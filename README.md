# 2026 부산 해운대 축제 사이트

단일 HTML 파일로 구현한 부산 해운대 축제 소개 사이트입니다.
탭 메뉴, 다크 글로시 카드, Supabase 연동 방명록, 토스트 알림, 축포 효과 등을 포함합니다.

---

## 1. 프로젝트 개요

- **프로젝트명**: 2026 부산 해운대 축제
- **기간**: 2026.08.01 ~ 08.15
- **형태**: 정적 단일 페이지(`index.html`)
- **목표**: 축제 정보 제공 + 방명록 실시간 연동

## 2. 주요 기능

| 기능 | 설명 |
|------|------|
| 탭 메뉴 | 홈 / 축제소개 / 프로그램 / 공연안내 / 오시는길 / 커뮤니티 |
| 홈 타일 | 사진 전체 배경 + 반투명 글로시 오버레이 카드, D-3 배지 |
| 더보기 토글 | 카드별 상세 정보 펼침/접기 |
| 방명록 | Supabase 연동, 글 작성/조회, 상대 시간 표시 |
| 토스트 알림 | Notyf 기반, 등록 성공/실패 피드백 |
| 축포 효과 | canvas-confetti, 방명록 등록 시 발사 |
| 검증 말풍선 | 빈 필드 제출 시 커스텀 스타일 말풍선 |
| 페이지 없음 모달 | 미구현 링크 클릭 시 "아직 준비중인 서비스" 모달 |

## 3. 사용 기술

- **HTML / CSS / Vanilla JavaScript** (외부 빌드 없음)
- **Supabase** — `guestbook` 테이블, RLS 공개 읽기/쓰기
- **Notyf** — 토스트 알림 라이브러리
- **Day.js** — 상대 시간 (`방금 전`, `5분 전`)
- **canvas-confetti** — 축포 효과

### 외부 라이브러리 (CDN)
```
@supabase/supabase-js@2
notyf@3
dayjs@1 (+ relativeTime 플러그인, ko locale)
canvas-confetti@1
```

## 4. 디자인 변천

요청에 따라 여러 시대 디자인으로 변환하며 최종적으로 2008년 애플 스타일로 완성:

1. **메트로 타일** (초기) — 라이브 타일 그리드
2. **2014 머터리얼 디자인** — App Bar, 카드 elevation, FAB
3. **2004 Web 2.0** — 글로시 그라디언트, 아쿠아 버튼
4. **2004 네이버** — 그린 테마, 서비스 탭, 박스형 콘텐츠
5. **2008 애플** (최종) — 어두운 글래스 내비, 다크 글로시 카드, Lucida/AppleGothic

### 최종 디자인 특징
- 어두운 해운대 비치 배경 (고정 + 어둡게 처리)
- 다크 글로시 카드/패널 (반투명 + backdrop-filter blur)
- 2톤 글로시 + 135도 빗금 피스트라이프 (토스트/말풍선/모달 공통)
- 모달: 위에서 내려오는 슬라이드 + 블러 페이드인/아웃 애니메이션
- 애플 아쿠아 블루 버튼

## 5. 방명록 데이터 구조

Supabase `public.guestbook` 테이블:

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `id` | uuid (PK) | 자동 생성 |
| `name` | text | 이름 |
| `message` | text | 메세지 |
| `created_at` | timestamptz | 작성 시간 |

- RLS 활성화 (공개 조회/작성)
- `created_at desc` 인덱스
